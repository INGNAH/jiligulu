# 已确定方向与阶段

当前美术定稿以 2026-11-19 确认的 Q 版像素餐桌角落为准。人物、背景、家具和最终呈现统一执行[母图规范](art/美术制作与交付说明.md)。

Windows独立游戏，Godot4。异世界餐厅经营；平面偏像素场景，二次元对话与资料卡插画。第一家回转小火锅，后续再设计其他店型。亲自操作和经营管理都要保留。

第一阶段餐厅核心：自由桌椅布局、供餐分区、餐带运输、房型、亲自烹饪补餐送餐、客人偏好、特殊点单、基础员工、日终与连续经营。v0.2已替换固定圆桌，提供双人桌椅套件、三分区、闭环路线、补餐点、三种房型及真实员工运输。独立椅子、更多家具、更多菜谱、完整美术仍需继续完善。不要将占位美术视为最终画风。

随后：
1. 白天逛市场、找商户，格子背包支持旋转与有限堆叠；随机商品、行情、事件和路线取舍，暂不做完整肉鸽。
2. 料理研发；传统工坊磨粉制面、分切、腌培根等；魔法工坊处理魔幻食材和特殊属性。允许买成品，也允许自建生产链。
3. 钓鱼、采集、农场、牧场；动物可送工坊加工。逐步委托员工，不要求每天全做。
4. 员工养成、个人剧情与恋爱；节庆、包场、更多特殊客人；分店与多店成长。

一天节奏：白天选择活动获取原料与研发，傍晚备菜排班，夜晚营业，打烊结算。节庆可贯穿全天。教程等流程稳定后融入第一天，不要在本阶段展开大教程。

文件交付：客户端直接下载大ZIP曾失败。相同文件改成`.download`后可下载，用户下载后改回`.zip`。优先提供单个完整包；不要继续GitHub Release上传，用户已明确停止该方案。未经指示不发布环境或推送仓库。
