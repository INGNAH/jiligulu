# 《我的火锅店》开发路线图 · 2026-11-23

穿越来的普通人在勇者和魔王交战的世界里开一家火锅店。玩家能改变今晚谁吃到了热饭、明天卖什么，以及谁还愿意回来。白天选活动，傍晚定菜单和排班，夜里营业，打烊看账与客评。

## 当前营业规则

客人在桌边向点单员点主菜，另一名送餐员从后厨取菜送桌。平价蔬菜、素食及蘸料、饮品、冰淇淋保留自取。

## 当前阶段 · 餐厅独立试玩

本轮确认的设计决定是保留店铺和自由装修，桌椅成组移动，就座只使用正面和背面。当前继续做餐厅 A1。用餐厅自身的备菜验证入座、取菜、入锅和结账。

餐厅之后，农场、牧场、工坊等场景逐个独立制作和试玩。各场景都能单独跑通后，最后再接跨场景库存、加工供货及经营反馈。下文涉及跨场景的例子供最终联动阶段参考。

## A · 餐厅独立营业试玩

以下功能已接入试玩。勾选表示程序流程已验证，美术与经营节奏留给试玩体验。

- [x] **A1 桌边点单与自取。** 双人桌每席一锅，点单员、送餐员站到桌旁服务。顾客到食材台取份，回座入锅后进食。自取盘显示满、大量、少量和空盘。当班补餐员从厨房取盘，优先处理缺菜和等候中的食材台。顾客在台前等补餐超过八秒会影响客评。首菜等待和上菜后的用餐计时分开记录。
- [x] **A2 店长的一晚。** 点击顾客接定制单，预留食材，入厨制作，送回原座。普通加单可略过，客人照常结账。准备期可投入原料研发固定菜谱，再挂到当晚菜单。顾客点菜时另有本餐口味要求。在料理台点击菜谱对应厨具，查看原方是否满足长期喜好与本餐要求，再选原味或额外加料。研发加料写入配方，营业加料只影响这一锅。
- [x] **A3 随工作切换的营业界面。** 大厅看单，料理台看食材和预留量，出餐窗看分区供应，出锅后提示送往哪一席。
- [x] **A4 可以搬家的厨房。** 营业家具中的料理台占两格，操作位和台体一起旋转、搬动，可撤销与存档。厨房员工从新位置工作，送餐员到料理台可达的最近出餐窗内侧取菜。无窗时直接在厨房交接。
- [x] **A5 看得见的布局后果。** 顾客走向本区沿通道最近的食材台，等主菜过久时显示等待秒数。打烊比较各区首菜、自取的平均用时，经营记录可查每桌首菜时间与客评。
- [x] **A7 菜单、翻台和口碑。** 开店前选普通主菜、自取菜和特别菜单。赶路客重视饱腹与用时，慕名客在意有没有吃到霜牛。打烊公告列实际留言、收支、小费与当前餐费下的次日客流预测。账本按开盘计供应用量，完整自取盘可回收。

## B · 一段吧台、三个常客、三个营业日

- [ ] **第一晚认识人。** 只做车夫、药师和另一位有鲜明口味的熟客。让玩家通过取菜动作、座位、短对话认识他们。用一条商路、一座东桥和迟到的送货人带出战争背景。商人借走一个筐，玩家可照常采购或提前囤耐放的菜。
- [ ] **第二晚第一次改菜单。** 牛肉延误，末班车带来赶路的人。玩家可以多备手工面，也能把剩余肉卷集中供应一小段吧台。打烊前魔族药师来借灶热药汤。接受占一个灶位，婉拒也能收店；允许一次善意没有即时金币回报。
- [ ] **第三晚认出自己的影响。** 有人专门回来问昨晚的面。玩家决定是否保留为常客菜。从记忆、账本、客评三处检查两条选择都说得通。后日谈再安排桥通货回、药师还锅或介绍香草种植户，留出时间差。
- [ ] **试玩复盘。** 玩家能否说出一位客人的口味、一次因商路而改的菜单，以及一个自己愿意记住的决定？三个问题答得出来，再增加事件数量。剧情例子与人物身份可改，先验证跨日因果。

## C · 把餐厅做成战争中的日常地点

- [ ] 逐步加入查车、缺货、宵禁、误解、离别与重逢。通过到货、商户口信、来客和座位变化预告；让玩家决定留库存、改打烊时间、留座或留最后一锅。阵营施压、要求拒客等较重情节由设计师定调后再写。
- [ ] 勇者队里的会计想分开结账，魔王军军需官惦记稳定出杯的冰淇淋。相邻两位客人最初隔一张空椅，熟悉后可能坐近。用重复的习惯和细小变化讲关系，保留轻松幽默和安静营业的夜晚。
- [ ] 将节庆、商户到访、包场、人气嘉宾或 coser 热场分别做成限时客群与菜单需求。测试活动带来的客流能否被当前等候区、菜量和员工接住。待核心稳定再加首日教程；分店、多店成长留给更后期。

## D · 后门外的生活，每次只接一个入口

下表顺序为建议。每项先在本场景验证一种产物和一次选择。表中回店反馈留到全部场景跑通后联调。基础食材和成品继续可以买，让白天能自由挑活动。

| 待办 | 第一轮可玩内容 | 回到店里如何验收 |
|---|---|---|
| □ 市场与背包 | 日常采购快捷订货；特殊集市、商队、远镇路线才使用格子背包。试旋转、有限堆叠与随机行情、商人和事件 | 一次在四格稀有锅具和六格便宜食材之间做取舍，回店看到两种菜单机会 |
| □ 料理研发 | 白天试锅底、季节菜和熟客配方；熟练菜缩短操作，首次研发与重要人物的菜给更多亲手制作空间 | 新菜能列入晚间菜单，熟客吃到后能记住 |
| □ 传统工坊 | 先做磨粉制面，再试腌培根、分切和保存；给现成采购与自主生产两种来源 | 今天的库存能变成下周断货时仍可供应的招牌菜 |
| □ 农场和采集 | 任选一块地、一季南瓜或一味野香草。保留向农户采购 | 有限收成可分到自取台或留给季节锅底，分别观察受益客人 |
| □ 钓鱼与鱼塘 | 允许用一个下午钓鱼、与常客闲聊；偶得怪鱼可做当晚限量菜 | 空手回店也能正常营业，钓到鱼或听到故事则多一个晚间选择 |
| □ 魔法工坊 | 首例用遇热开花的菇，试加工如何改变锅中呈现与客人反应 | 玩家能从餐桌动作认出魔法食材的价值，定价只是其中一项 |
| □ 牧场 | 先定动物情感与加工边界，再试奶、蛋、羊毛或牧户供肉；保留长期饲养关系与日后委托 | 一种自产物能做成自家招牌，玩家清楚为动物命名、培养关系意味着什么 |
| □ 员工成长、个人线与恋爱 | 先做可见的工作专长，如记得谁怕辣、为缺菜的自取台补餐、去门口招呼犹豫的客人，再接打烊后的个人事件 | 纯同事路线也有完整岗位成长；亲密路线增加相处方式与故事。后期可委托日常生产 |

## 三个需要设计师拍板的问题

1. **在 A2 前定烹饪重心。** 玩家更享受控火下料，还是读懂口味、决定做什么？先试“熟菜快做，研发和人物菜细做”，按连续营业后的重复感调整。
2. **在 B 的剧情定稿前定战争尺度。** 温暖日常能否承受阵营施压或拒客？先从商路、宵禁和重逢写起。主角能影响人的一晚，其能力与代价要和普通店长的身份一致。
3. **在 A7 与 B 验收前定餐厅声誉的首位目标。** 玩家最想让人记住的是稀有食材、总想回来的一锅，还是敌对双方也能同桌的地方？答案将决定评价权重、菜单奖励、主线与结局。牧场动物加工的选择另在 D 的牧场立项前确认。
