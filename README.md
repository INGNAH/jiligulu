# 星灯回转锅 · 餐厅核心 v0.3.2

[下载当前 Windows 试玩包](https://github.com/INGNAH/jiligulu/raw/refs/heads/main/releases/StarPot-Buffet-Windows.zip)。本版包含自助餐营业、街区快报、临时餐厅美术和约三头身的像素店长。解压运行 StarPot/StarPot.exe。

Godot 4.6.3 / Windows x86_64 独立游戏原型。当前以可玩经营规则为主，使用程序绘制的占位美术。最终视觉方向为偏像素平面经营场景、二次元角色资料卡与对话立绘。

## 经营一晚

WASD / 方向键移动，靠近设施按 E，Esc 关闭面板，P 暂停，F11 切换全屏。查看手册时暂停营业。

1. 左上市场采购，左下料理台装盘：1份原料制作2盘食物。
2. 右侧地板是可规划的餐厅区域；默认6张桌、12座，分为青叶和紫月两区，可直接开店。
3. 左侧开店铃可以招聘露米、分配岗位和开门。至少准备12盘，建议30盘左右。基础餐费24金，吃不满3盘但吃过至少1盘收12金，没吃到不收费。
4. 数字1—7或底部菜品按钮选菜；到料理台按 E 取一盘，再到彩色“补”字补餐点按 E 放上传送带。Q放回手里的菜。
5. 客人自动取餐，每隔至少5秒吃一盘。气泡是额外喜好，靠近客人 E 定向送餐。普通客人奖励6金，莱恩需要清淡肉，牛肉或清炖霜牛均可，奖励18金和好感。
6. 一晚最多150秒；餐费18/24/30金分别对应12/10/8位客人。日终查看各区评价、缺餐等待、成本与利润，进入下一天。

第一晚可采购：牛肉两组、蘑菇两组、豆腐一组，花费63金。保留一份牛肉和豆腐尝试炖菜，其余装盘。露米招聘30金，每晚工资8金。

## 自由布局（准备期 B）

工具栏支持：放桌椅、移动、铺餐带、补餐点、改分区、拆除、撤销、房型切换、还原布局。

- 放桌椅：左键放一套双人桌椅，R旋转。绿色预览可放，红色表示重叠或没有地板。
- 移动：先点击已有桌椅，再点击目标格；R可旋转，右键取消。只有成功放置才移动原桌。
- 铺餐带：左键逐格铺设或拖画。每格需上下左右连接，形成同区闭环；最短8格，不能有分岔。餐盘按箭头方向行进。
- 分区：工具栏“分区”或数字1/2/3选择青叶、紫月、金穗。放置时自动归区；“改分区”工具可以修改桌子、餐带、补餐点。
- 补餐点：放在餐带紧邻的空地板格上，与餐带同区。一条环路可以设置多个补餐点。
- 右键拆除或使用拆除工具；可以撤销最近40次编辑。
- 房型：方形、长条、L形。切换保留已有家具，移动或拆除超出地板部分后再开门。“还原布局”需确认，恢复默认方形双区，资金和库存不变。
- 编辑免费，营业中锁定布局。桌椅不能重叠，座位必须能从右下入口到达，补餐点必须能从左下厨房通道到达。断开的餐带、缺补餐点、桌子不邻接同区餐带等问题会阻止开店。

当前桌子以一套桌子+两个座位放置，尚未支持逐个摆椅子、任意尺寸家具、房型购买或施工费用。餐带必须闭环，未实现分流器与跨区连接。

## 供餐与员工

- 各区独立供餐，餐盘不跨环路瞬移。一格运输需约0.56秒，餐带越长绕行越久。路线显示一圈需要的时间和当前餐盘数量。
- 容量按路线长度计算，每两格约容纳一盘。
- 超过10秒没有吃到下一盘的饥饿客人累积缺餐等待，影响日终评价；未满足额外喜好本身不扣分。
- 露米初始每次携带最多3盘，三级提升为4盘，实际沿通道往返厨房和补餐点。空位不足时未放下的餐盘退回备餐库存。
- 可以选择自动巡区或指定负责一个区；自动巡区优先补需求较高的餐带。基础食材优先匹配客人口味，清炖霜牛留给玩家亲自送。
- 增设靠近厨房的补餐点、缩短绕行路线、给不同区域安排供餐职责，都能影响实际效率。

## 烹饪与保存

清炖霜牛需要牛肉和豆腐各1份，在火候条40—70出锅，成功产出2盘并增加熟练度。失误改成普通牛肉盘；成功3次后解锁快捷制作。目前只做了一种烹饪小游戏，委托烹饪与更多菜谱后续扩展。

主菜单提供三个独立存档位、新游戏与继续游戏，覆盖已有存档需确认。准备期在手册或暂停菜单保存，开门前和日终自动保存。存档包含布局、房型、分区、员工岗位、资金、食材、熟练度和好感。兼容v0.1存档，旧档自动使用默认双区布局。营业过程暂不保存；营业中退出后恢复开门前的检查点。退出会提示确认。每个存档保留上一份有效备份，主文件损坏时尝试恢复，写入失败会明确提示。

Windows存档通常位于 `%APPDATA%/Godot/app_userdata/星灯回转锅 · Demo/saves/slot_1.json`（另有slot_2、slot_3与各自.bak备份）。旧版 `starpot.json` 可从主菜单导入空位，原文件保留。设置单独保存在 `settings.cfg`。字体Noto Sans CJK许可证见 `hotpot/assets/FONT-LICENSE.txt`。

## v0.3 新增经营与基础流程

- 开店管理中切换18、24、30金餐费；高价降低客流并提高评价要求，未吃饱但吃过的客人收半价。
- 料理台支持一键批量装盘，消耗全部基础原料，每份制作2盘；需要研发炖菜时请先留原料。
- 露米每趟成功补餐获得1经验，完成营业额外2经验；30/60经验升至二/三级，步速提升，三级多携带1盘。每日工资仍为8金。
- 日终报表增加各菜品销量、当前餐费、总食用盘数与员工补餐次数和经验。
- 暂停菜单支持继续、保存、设置、返回主菜单和退出；设置包括全屏、切换窗口自动暂停与总音量。当前尚未制作音乐音效。
- UI和场景仍使用占位美术，资源接入接口保留，可在用户设计完成后替换。

新增验证：`XDG_DATA_HOME=/tmp/starpot-session-test godot --headless --path hotpot --script res://tests/session.gd`。本轮43项会话与经营检查，连同已有18项经营、35项布局、19项美术接口检查，共115项通过。`tests/app_visual.gd` 验证原生窗口下新游戏、暂停、设置、结算、返回主菜单及继续的鼠标和键盘流程。

## v0.3.1 营业准备

市场、料理台和开店铃新增库存与备菜计划。按当前餐费预计客流，每客3盘计算总量，已有炖菜与基础成品均计入；六种基础菜按库存均衡补齐。清单扣除现有原料，再按每组3份计算购买数量及费用。可以按清单采购、按计划装盘，多余原料保留。资金不足不会部分采购，重复操作不会超额购买。

开店检查显示现有与建议餐盘数量，以及人手和工资提醒。12盘仍是开门下限，建议数量只作经营参考，不保证口味满足或配送及时。采购和装盘仅在准备期可执行。新增15项检查通过，连同此前115项共130项。

## v0.3.2 跨天营业记录

店长手册与日终结算新增经营记录入口，保留最近30个营业日。可以查看最近7次营业的收入、支出、净收益、客流、销量和按客人数加权的评价，并比较最近两次营业的收入、净收益与客流变化。每天的明细包括当日餐费、桌数、餐带数、菜品销量和分区评价及缺餐等待时间。

记录随三个存档位分别保存；旧档兼容，未记录的历史不会补造。支出按实际付款日计入，包含采购、招聘、装修和工资，不代表已售食材成本。新增18项检查，连同原有130项共148项通过。
